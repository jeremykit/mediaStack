# 登出按钮功能设计文档

**日期**: 2026-03-05
**状态**: 已批准

## 需求概述

在登录状态下，为用户首页和管理后台添加登出按钮功能，提供清晰的退出登录路径。

## 当前状态

| 页面 | 登出按钮 | 状态 |
|------|----------|------|
| 用户首页 (`Home.vue` + `HeaderNav`) | 已存在 | ✅ 需添加确认对话框 |
| 管理后台 (`admin/Layout.vue`) | 不存在 | ❌ 需新增 |

## 设计方案

### 用户首页 (`HeaderNav.vue`)

**现状**：已包含登出按钮，但直接执行登出无确认

**修改**：
- 添加 `ElMessageBox.confirm` 确认对话框
- 提示文字："确定要登出吗？"
- 登出后停留在首页，自动刷新界面状态
- 刷新后登录状态变为未登录，按钮变为"登录"

### 管理后台 (`admin/Layout.vue`)

**新增位置**：

1. **顶部 Header 右侧**（与"返回首页"按钮并排）
   - 样式：🔒 登出
   - 点击 → 确认对话框 → 登出 → 跳转登录页

2. **侧边栏底部用户区域**（user-profile 区域）
   - 将 user-profile 改为可点击区域
   - 或在右侧添加独立的登出按钮
   - 样式：🔒 登出
   - 点击 → 确认对话框 → 登出 → 跳转登录页

### 交互流程

```
用户点击登出按钮
    ↓
弹出确认对话框："确定要登出吗？"
    ↓
    ├─ 取消 → 关闭对话框，留在当前页面
    │
    └─ 确定 → 执行登出
              ↓
         调用 authStore.logout()
              ↓
    ┌─────────┴─────────┐
    ↓                   ↓
用户首页          管理后台
停留在首页          跳转 /login
刷新状态
```

### UI/UX 细节

| 元素 | 规格 |
|------|------|
| 图标 | 🔒 锁图标（SVG） |
| 文字 | "登出" |
| 按钮样式 | 与页面现有按钮风格保持一致 |
| 对话框类型 | Element Plus `ElMessageBox.confirm` |
| 对话框标题 | "提示" |
| 对话框内容 | "确定要登出吗？" |

## 技术实现要点

### 依赖
- `authStore.logout()` - 已存在
- `ElMessageBox.confirm` - Element Plus 提供
- `useRouter` - Vue Router

### 文件修改清单

| 文件 | 修改类型 | 说明 |
|------|----------|------|
| `frontend/src/components/HeaderNav.vue` | 修改 | 添加确认对话框逻辑 |
| `frontend/src/views/admin/Layout.vue` | 修改 | 添加两处登出按钮和逻辑 |

## 验收标准

1. 用户首页点击登出 → 弹出确认框 → 确认后停留在首页，状态刷新为未登录
2. 管理后台顶部点击登出 → 弹出确认框 → 确认后跳转到登录页
3. 管理后台侧边栏点击登出 → 弹出确认框 → 确认后跳转到登录页
4. 取消登出时不执行任何操作，留在当前页面
